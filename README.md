# Elsevier PDF Helper for Zotero

A small Zotero plugin for attaching legally accessible Elsevier/ScienceDirect PDFs to selected Zotero items.

## Features

- Adds an `Elsevier PDF` menu in Zotero.
- Opens Elsevier institutional authorization inside Zotero.
- Downloads PDFs only through legal access available to Zotero.
- Supports selected-item and current-view batch processing.
- Adds status tags such as `PDF/Elsevier已下载`, `PDF/Elsevier下载失败`, and `PDF/无合法访问权限`.
- Uses a randomized delay for batch download attempts to reduce blocking risk.

## Install

1. In Zotero, open `Tools > Add-ons`.
2. Choose `Install Add-on From File`.
3. Select `elsevier-pdf-helper-0.2.5.xpi`.
4. Restart Zotero if prompted.

## Notes

This plugin does not include or use Sci-Hub, account passwords, browser cookie extraction, or any unauthorized access mechanism.
